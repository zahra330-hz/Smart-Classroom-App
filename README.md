# 🎓 Students Management System

A simple, interactive Python-based system to manage student grades. This project demonstrates the use of all basic Python data types and interactive logic.

## 🚀 Features
- **Check Status**: Search for a student to see if they passed or failed.
- **View All**: Display a full list of students with their respective grades.
- **Calculate Average**: Get the class average grade instantly.
- **Add New Students**: Dynamically add new students to the record during runtime.
- **Input Validation**: Prevents the program from crashing if a non-numeric grade is entered.

## 🛠 Variables Used
- **Strings**: Project name, version, and author.
- **Integers/Floats**: Minimum passing grades and student scores.
- **Lists**: Maintaining the sequence of student names.
- **Dictionaries**: Mapping student names to their grades (Key-Value pairs).
- **Booleans**: Logic for "Passed" or "Failed" status.
- **Tuples**: Fixed system information.

## 🖥 How to Run
1. Make sure you have **Python** installed.
2. Run the script using the terminal:
   ```bash
   python management.py
   ```

## ⌨️ Commands
- Type a **Student Name** (e.g., `Ali`) to check their status.
- Type `all` to see the entire list.
- Type `average` to calculate the class mean.
- Type `exit` to close the program.
